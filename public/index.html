🚀 How to Deploy this Site on Netlify

We have already created the netlify.toml configuration and public/ build folder for you!

1
Push to GitHub

Push this repository to your GitHub account using AI Studio's export or git push.

2
Connect to Netlify

Go to app.netlify.com & select "Add new site" → "Import from Git".

3
Automatic Settings

Netlify automatically detects netlify.toml and sets Publish Directory to public.

4
Instant Live URL

Click Deploy Site! Your website goes live with free HTTPS and global CDN in under 30 seconds.

⚡ Direct Drag & Drop Option: You can also drag the public folder straight onto app.netlify.com/drop for instant zero-config hosting!
